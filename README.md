# 缄默之秋创意工坊

这是《缄默之秋》扩展包的编辑、校验、发布与安装协议仓库。在线编辑器面向普通玩家设计，不要求作者理解 ZOD、MVU 或工坊协议。

## 使用编辑器

打开 [创意工坊编辑器](https://nlkashei.github.io/JMZQ-WORKSHOP/)，按页面引导完成：

1. 选择“轻量扩展”或“完整改造”；
2. 填写给玩家看的名称和简介；
3. 新建或导入 SillyTavern 世界书条目；
4. 如有需要，从本体数据树中点选条目的出现条件；
5. 检查、导出并投稿。

编辑器每次修改后会自动保存，并每 30 秒补做一次保存。世界书编辑支持蓝灯常驻、绿灯关键词、链式向量、插入位置与角色、概率、递归、包含组、角色过滤和定时效果等设置。技术字段默认收进高级设置。

变量选择器由 `缄默之秋3.0/MVU变量/ZOD.js` 自动生成。更新本体 ZOD 后运行：

```powershell
npm run build:zod-catalog
```

## 扩展类型

### 兼容扩展

兼容扩展不替换 ZOD、状态栏、正则或小助手，只能：

- 新增世界书条目；
- 根据原版 MVU 变量启停自己的条目；
- 在 `工坊扩展.<作品ID>.数据` 中保存自己的运行状态；
- 读取清单中明确声明的原版变量。

兼容扩展可以由小助手安装、更新、停用和卸载。

### 深度改造

深度改造会替换或修改 ZOD、状态栏、正则、小助手或其他核心组件。此类作品使用安装指导、版本指纹、冲突提示和备份流程，不进入兼容扩展的自动路由。
